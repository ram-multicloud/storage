# Azure Windows VM — Attach New Disk

## Method 1: PowerShell

### 1. Attach the disk (from Azure CLI, if not already attached)

```powershell
az vm disk attach --resource-group MyRG --vm-name MyVM --name MyNewDataDisk --new --size-gb 128
```

### 2. On the VM — find the new disk

```powershell
Get-Disk
```

Look for the disk with `OperationalStatus: Offline` and `PartitionStyle: RAW`. Note its `Number` (e.g. `2`).

### 3. Bring the disk online

```powershell
Set-Disk -Number 2 -IsOffline $false
```

### 4. Initialize the disk

```powershell
Initialize-Disk -Number 2 -PartitionStyle GPT
```

### 5. Create the partition with drive letter D

```powershell
New-Partition -DiskNumber 2 -UseMaximumSize -DriveLetter D
```

### 6. Format the partition

```powershell
Format-Volume -DriveLetter D -FileSystem NTFS -NewFileSystemLabel "DataDisk" -Confirm:$false
```

### 7. Verify

```powershell
Get-Volume -DriveLetter D
Get-Disk
```

### One-liner (init → partition → format)

```powershell
Get-Disk | Where-Object PartitionStyle -Eq 'RAW' |
    Initialize-Disk -PartitionStyle GPT -PassThru |
    New-Partition -DriveLetter D -UseMaximumSize |
    Format-Volume -FileSystem NTFS -NewFileSystemLabel "DataDisk" -Confirm:$false
```

## Method 2: GUI (Disk Management)

1. **Open Disk Management**
   Press `Win + R`, type `diskmgmt.msc`, press Enter.

2. **Find the new disk**
   It will appear as **Not Initialized**, shown as a black bar labeled "Unknown / Not Initialized," usually at the bottom of the disk list.

3. **Initialize the disk**
   Right-click the disk (on the left panel where it says "Disk 2," etc.) → **Initialize Disk**. Select **GPT (GUID Partition Table)** → click **OK**.

4. **Create a new volume**
   Right-click the **unallocated space** next to the disk → **New Simple Volume** → click **Next**.

5. **Specify volume size**
   Accept the default (maximum size) → click **Next**.

6. **Assign drive letter**
   Choose **D** from the drop-down → click **Next**.

7. **Format the volume**
   - File system: **NTFS**
   - Allocation unit size: **Default**
   - Volume label: e.g. `DataDisk`
   - Check **Perform a quick format**
   - Click **Next** → **Finish**

8. **Verify**
   Open **File Explorer** → confirm **D:** drive appears with the assigned label and correct size.
