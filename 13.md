# Azure Blob Storage

## What is Blob Storage

Azure Blob Storage is Microsoft's object storage service for unstructured data — files, images, videos, logs, backups, and any binary or text data that doesn't fit a structured database model. Data is stored as **blobs** inside **containers**, which live inside a **storage account**.

## Types of Blobs

| Type | Description | Common Use Case |
|---|---|---|
| **Block Blob** | Data is broken into blocks, each uploaded independently and committed as a set. Optimized for large amounts of data uploaded efficiently. | Documents, images, videos, backups, general file storage |
| **Append Blob** | Made up of blocks like a block blob, but optimized for append-only operations — new data can only be added to the end. | Logging, audit trails, streaming writes |
| **Page Blob** | Made up of 512-byte pages, optimized for random read/write access. | Virtual Hard Disk (VHD) files backing Azure VMs |

## Storage Account Tiers (relevant when creating one)

- **Hot** — frequently accessed data, higher storage cost, lower access cost
- **Cool** — infrequently accessed data (30+ days), lower storage cost, higher access cost
- **Cold** — rarely accessed data (90+ days), even lower storage cost
- **Archive** — rarely accessed, offline data, lowest storage cost, high retrieval latency

## Steps: Create Blob Storage via Azure Portal

1. **Sign in** to the [Azure Portal](https://portal.azure.com).
2. Click **Create a resource** → search for **Storage account** → click **Create**.
3. **Basics tab:**
   - Select a **Subscription** and **Resource Group** (or create a new one).
   - Enter a globally unique **Storage account name** (lowercase letters/numbers only).
   - Choose a **Region**.
   - Select **Performance**: Standard or Premium.
   - Select **Redundancy**: LRS, ZRS, GRS, or GZRS.
4. **Advanced tab (optional):** Configure security settings like requiring secure transfer, blob soft delete, and versioning.
5. **Networking tab:** Choose public access or configure a private endpoint/VNet.
6. **Data protection tab:** Enable soft delete, versioning, or change feed if needed.
7. Click **Review + Create**, then **Create** once validation passes.
8. Once deployed, go to the storage account → **Containers** → **+ Container**.
9. Give the container a name and set the **Public access level** (Private, Blob, or Container).
10. Click **Create**. You can now upload blobs into this container via **Upload**.

## Steps: Create Blob Storage via Azure CLI

```bash
# 1. Login
az login

# 2. Create a resource group (skip if one exists)
az group create --name myResourceGroup --location eastus

# 3. Create the storage account
az storage account create \
  --name mystorageacct123 \
  --resource-group myResourceGroup \
  --location eastus \
  --sku Standard_LRS \
  --kind StorageV2

# 4. Create a blob container
az storage container create \
  --account-name mystorageacct123 \
  --name mycontainer \
  --auth-mode login

# 5. Upload a blob (block blob by default)
az storage blob upload \
  --account-name mystorageacct123 \
  --container-name mycontainer \
  --name myfile.txt \
  --file ./myfile.txt \
  --auth-mode login
```

## Example: Creating Each Blob Type via CLI

### Block Blob (default type — general file upload)

```bash
az storage blob upload \
  --account-name mystorageacct123 \
  --container-name mycontainer \
  --name report.pdf \
  --file ./report.pdf \
  --type block \
  --auth-mode login
```

### Append Blob (create empty, then append data — e.g. a log file)

```bash
# Create the empty append blob
az storage blob upload \
  --account-name mystorageacct123 \
  --container-name mycontainer \
  --name app.log \
  --file /dev/null \
  --type append \
  --auth-mode login

# Append a line to it
echo "$(date) - service started" > entry.txt
az storage blob upload \
  --account-name mystorageacct123 \
  --container-name mycontainer \
  --name app.log \
  --file entry.txt \
  --type append \
  --auth-mode login
```

### Page Blob (fixed-size, random read/write — e.g. a VHD)

```bash
# Page blobs must have a size that is a multiple of 512 bytes
az storage blob create \
  --account-name mystorageacct123 \
  --container-name mycontainer \
  --name disk.vhd \
  --type page \
  --content-length 1073741824 \
  --auth-mode login
```

## Notes

- Storage account names must be globally unique across all of Azure.
- Container access levels: **Private** (no anonymous access), **Blob** (anonymous read for blobs only), **Container** (anonymous read for container and blobs).
- Use `--type` with `az storage blob upload` (values: `block`, `append`, `page`) if you need a non-default blob type.
