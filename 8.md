# Amazon Athena - CRUD Queries (S3 Table)

Amazon Athena queries data directly from S3 using tables defined in the AWS Glue Data Catalog. Standard Athena tables (backed by CSV, JSON, Parquet, etc.) are **read-only for INSERT/UPDATE/DELETE** unless the table format is **Apache Iceberg**, which adds full CRUD support.

---

## 1. CREATE TABLE

### Standard external table (S3-backed, read-only)

```sql
CREATE EXTERNAL TABLE IF NOT EXISTS employees (
    emp_id INT,
    emp_name STRING,
    department STRING,
    salary DOUBLE
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION 's3://my-athena-bucket/employees/';
```

### Iceberg table (supports INSERT/UPDATE/DELETE)

```sql
CREATE TABLE employees_iceberg (
    emp_id INT,
    emp_name STRING,
    department STRING,
    salary DOUBLE
)
LOCATION 's3://my-athena-bucket/employees_iceberg/'
TBLPROPERTIES ('table_type' = 'ICEBERG');
```

---

## 2. INSERT DATA

```sql
INSERT INTO employees_iceberg (emp_id, emp_name, department, salary)
VALUES
    (1, 'Ravi Kumar', 'Engineering', 75000),
    (2, 'Anita Sharma', 'HR', 60000),
    (3, 'Suresh Reddy', 'Sales', 55000);
```

Insert from another table/query:

```sql
INSERT INTO employees_iceberg
SELECT emp_id, emp_name, department, salary
FROM employees_staging
WHERE department = 'Engineering';
```

---

## 3. READ / SELECT

```sql
SELECT *
FROM employees_iceberg
WHERE department = 'Engineering';
```

---

## 4. UPDATE (Iceberg only)

```sql
UPDATE employees_iceberg
SET salary = 80000
WHERE emp_id = 1;
```

---

## 5. DELETE (Iceberg only)

```sql
DELETE FROM employees_iceberg
WHERE emp_id = 3;
```

Delete all rows:

```sql
DELETE FROM employees_iceberg;
```

---

## 6. DROP TABLE

```sql
DROP TABLE IF EXISTS employees_iceberg;
```

> Note: `DROP TABLE` on an external table removes only the Glue Catalog metadata, not the underlying S3 data, unless it's a managed Iceberg table without `external_location` overrides.

---

## Key Notes

| Operation | Standard Table (CSV/Parquet/JSON) | Iceberg Table |
|---|---|---|
| CREATE | ✅ | ✅ |
| INSERT | ❌ (use `INSERT INTO` only with CTAS-supported formats) | ✅ |
| UPDATE | ❌ | ✅ |
| DELETE | ❌ | ✅ |
| DROP | ✅ (metadata only) | ✅ |

- Standard Athena tables are append-only via `INSERT INTO ... SELECT` for some formats (e.g., Parquet), but do not support `UPDATE`/`DELETE`.
- For full CRUD, always create the table with `TBLPROPERTIES ('table_type' = 'ICEBERG')`.
