# Create MySQL DB, Table, and Insert Sample Data on AWS RDS

## Step 1: Create the RDS MySQL Instance

### Via Console
1. Go to **RDS → Databases → Create database**
2. Choose **Standard create**
3. Engine: **MySQL**
4. Template: **Free tier**
5. DB instance identifier: `mysql-classroom-db`
6. Master username: `admin`
7. Master password: set a password
8. DB instance class: `db.t3.micro`
9. Storage: `gp3`, 20 GB
10. Connectivity:
    - VPC: default (or your VPC)
    - Public access: **Yes**
    - VPC security group: create new or select existing
11. Click **Create database**, wait for status **Available**

### Via CLI
```bash
aws rds create-db-instance \
  --db-instance-identifier mysql-classroom-db \
  --db-instance-class db.t3.micro \
  --engine mysql \
  --master-username admin \
  --master-user-password ChangeMe123! \
  --allocated-storage 20 \
  --publicly-accessible \
  --vpc-security-group-ids sg-xxxxxxxx
```

## Step 2: Open the Security Group

Add an inbound rule to allow MySQL traffic:

| Type | Protocol | Port | Source |
|---|---|---|---|
| MySQL/Aurora | TCP | 3306 | Your IP |

## Step 3: Get the Endpoint

RDS console → your DB instance → **Connectivity & security** → copy the **Endpoint**:

```
mysql-classroom-db.abcdefg12345.us-east-1.rds.amazonaws.com
```

## Step 4: Connect to the Instance

```bash
mysql -h mysql-classroom-db.abcdefg12345.us-east-1.rds.amazonaws.com \
      -P 3306 \
      -u admin \
      -p
```

Enter the master password when prompted.

## Step 5: Create a Database

```sql
CREATE DATABASE classroom_db;
USE classroom_db;
```

## Step 6: Create a Table

```sql
CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    course VARCHAR(100),
    enrolled_date DATE
);
```

## Step 7: Insert Sample Data

```sql
INSERT INTO students (name, course, enrolled_date) VALUES
('Alice Johnson', 'DevOps Fundamentals', '2026-01-10'),
('Bob Smith', 'AWS Cloud Practitioner', '2026-02-15'),
('Charlie Lee', 'Docker & Kubernetes', '2026-03-05');
```

## Step 8: Verify the Data

```sql
SELECT * FROM students;
```

```sql

```
