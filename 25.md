# Azure Databases (Non-SQL): Create, Insert Data, Get Data

Azure's relational services (Azure SQL Database, Azure Database for MySQL, Azure Database for PostgreSQL) are the counterpart of AWS RDS, so they are not covered here. This guide covers Azure's purpose-built databases, using the same two students as the AWS guide:

| id | name | course |
|---|---|---|
| S001 | Ravi | DevOps |
| S002 | Sita | Azure |

## AWS to Azure Mapping

| AWS | Azure |
|---|---|
| DynamoDB | Cosmos DB for NoSQL, Azure Table Storage |
| DocumentDB | Cosmos DB for MongoDB |
| Keyspaces | Cosmos DB for Apache Cassandra |
| Neptune | Cosmos DB for Apache Gremlin |
| ElastiCache / MemoryDB | Azure Managed Redis |
| OpenSearch Service | Azure AI Search |
| Timestream / analytics | Azure Data Explorer |

> Prerequisites: an Azure subscription, the Azure CLI (`az login`), and a resource group. All CLI examples assume:

```bash
az group create --name rg-db-demo --location centralindia
```

---

## 1. Cosmos DB for NoSQL

### Create (Portal)
1. Search **Azure Cosmos DB**, click **Create**, choose **Azure Cosmos DB for NoSQL**.
2. Select the **Subscription** and **Resource group** `rg-db-demo`.
3. **Account name**: `mycosmos<unique>`, choose the **Location**.
4. **Capacity mode**: **Serverless** (best for practice) and click **Review + create**, then **Create**.
5. Open the account, go to **Data Explorer**, click **New Container**.
6. **Database id**: `school`, **Container id**: `students`, **Partition key**: `/course`.

### Create (CLI)

```bash
az cosmosdb create --name mycosmos12345 --resource-group rg-db-demo \
  --locations regionName=centralindia --capabilities EnableServerless

az cosmosdb sql database create --account-name mycosmos12345 \
  --resource-group rg-db-demo --name school

az cosmosdb sql container create --account-name mycosmos12345 \
  --resource-group rg-db-demo --database-name school \
  --name students --partition-key-path "/course"
```

### Insert data
In **Data Explorer**, open `students`, then **Items**, then **New Item**, paste and click **Save**:

```json
{ "id": "S001", "name": "Ravi", "course": "DevOps" }
```

```json
{ "id": "S002", "name": "Sita", "course": "Azure" }
```

### Get data
In Data Explorer click **New SQL Query**:

```sql
SELECT * FROM c
SELECT * FROM c WHERE c.course = 'DevOps'
SELECT c.name FROM c WHERE c.id = 'S002'
```

## 2. Cosmos DB for MongoDB

### Create (Portal)
1. **Azure Cosmos DB**, **Create**, choose **Azure Cosmos DB for MongoDB** (vCore or RU based; RU is easiest to try).
2. Fill in the resource group, account name, and location, then **Create**.
3. After deployment, open **Connection strings** and copy the primary connection string.

### Create (CLI)

```bash
az cosmosdb create --name mymongo12345 --resource-group rg-db-demo \
  --kind MongoDB --server-version 7.0 \
  --locations regionName=centralindia

az cosmosdb mongodb database create --account-name mymongo12345 \
  --resource-group rg-db-demo --name school
```

### Insert and get data (mongosh)

```bash
mongosh "<primary-connection-string>"
```

```javascript
use school

db.students.insertOne({ _id: "S001", name: "Ravi", course: "DevOps" })
db.students.insertOne({ _id: "S002", name: "Sita", course: "Azure" })

db.students.find()
db.students.find({ course: "DevOps" })
db.students.findOne({ _id: "S002" })
```

## 3. Cosmos DB for Apache Cassandra

### Create (Portal)
1. **Azure Cosmos DB**, **Create**, choose **Azure Cosmos DB for Apache Cassandra**.
2. Fill in the details and **Create**.
3. In **Data Explorer**, click **New Table**, enter a **Keyspace name** `school`, **Table id** `students`, and define the columns.

### Create (CLI)

```bash
az cosmosdb create --name mycassandra12345 --resource-group rg-db-demo \
  --capabilities EnableCassandra --locations regionName=centralindia

az cosmosdb cassandra keyspace create --account-name mycassandra12345 \
  --resource-group rg-db-demo --name school
```

### Create table, insert, and get (cqlsh)
Connect with `cqlsh` using the host, port `10350`, username, and password from **Connection strings**, with SSL enabled.

```sql
CREATE TABLE school.students (
  id text PRIMARY KEY,
  name text,
  course text
);

INSERT INTO school.students (id, name, course) VALUES ('S001', 'Ravi', 'DevOps');
INSERT INTO school.students (id, name, course) VALUES ('S002', 'Sita', 'Azure');

SELECT * FROM school.students;
SELECT name, course FROM school.students WHERE id = 'S001';
```

## 4. Cosmos DB for Apache Gremlin (Graph)

### Create (Portal)
1. **Azure Cosmos DB**, **Create**, choose **Azure Cosmos DB for Apache Gremlin**.
2. After deployment, open **Data Explorer**, click **New Graph**.
3. **Database id**: `school`, **Graph id**: `people`, **Partition key**: `/pk`.

### Create (CLI)

```bash
az cosmosdb create --name mygraph12345 --resource-group rg-db-demo \
  --capabilities EnableGremlin --locations regionName=centralindia

az cosmosdb gremlin database create --account-name mygraph12345 \
  --resource-group rg-db-demo --name school

az cosmosdb gremlin graph create --account-name mygraph12345 \
  --resource-group rg-db-demo --database-name school \
  --name people --partition-key-path "/pk"
```

### Insert and get data (Data Explorer, Graph query box)

```groovy
g.addV('student').property('id','S001').property('name','Ravi').property('pk','S001')
g.addV('course').property('id','C1').property('name','DevOps').property('pk','C1')
g.V('S001').addE('enrolled_in').to(g.V('C1'))
```

```groovy
g.V().hasLabel('student').values('name')
g.V('S001').out('enrolled_in').values('name')
```

## 5. Azure Table Storage

Cheap key-value storage that lives inside a **Storage account**.

### Create (Portal)
1. Search **Storage accounts**, click **Create**, fill in the resource group, name, and region, then **Create**.
2. Open the account, then **Storage browser**, then **Tables**, then **Add table**, name it `students`.

### Create (CLI)

```bash
az storage account create --name mystorage12345 \
  --resource-group rg-db-demo --location centralindia --sku Standard_LRS

az storage table create --name students --account-name mystorage12345
```

### Insert data

```bash
az storage entity insert --account-name mystorage12345 --table-name students \
  --entity PartitionKey=DevOps RowKey=S001 name=Ravi

az storage entity insert --account-name mystorage12345 --table-name students \
  --entity PartitionKey=Azure RowKey=S002 name=Sita
```

### Get data

```bash
# One row by keys
az storage entity show --account-name mystorage12345 --table-name students \
  --partition-key DevOps --row-key S001

# Filter
az storage entity query --account-name mystorage12345 --table-name students \
  --filter "PartitionKey eq 'DevOps'"
```

> Add `--auth-mode login` to the commands if you sign in with your Azure account instead of using a storage key.

## 6. Azure Managed Redis

> Azure Cache for Redis (Basic, Standard, Premium, Enterprise) is being retired, and Microsoft has blocked new creation on a published timeline. **Use Azure Managed Redis** for new work.

### Create (Portal)
1. Search **Azure Managed Redis**, click **Create**.
2. Choose the resource group, **Name** `my-amr`, **Region**.
3. **Cache SKU**: choose the smallest option for practice (for example **Balanced B0**).
4. Click **Review + create**, then **Create**.
5. Open the resource, and under **Authentication** copy the **Access keys**. Copy the **Endpoint** from **Overview**.

### Create (CLI)

```bash
az redisenterprise create --name my-amr --resource-group rg-db-demo \
  --location centralindia --sku Balanced_B0
```

### Insert and get data

```bash
redis-cli -h <endpoint> -p 10000 --tls -a <access-key>
```

```
SET student:S001 "Ravi"
HSET student:S002 name "Sita" course "Azure"

GET student:S001
HGETALL student:S002

SET session:1001 "ravi" EX 300
TTL session:1001
```

## 7. Azure AI Search (Full-text Search)

### Create (Portal)
1. Search **AI Search**, click **Create**.
2. Choose the resource group, **Service name** `mysearch12345`, **Location**, and **Pricing tier** **Free**.
3. Click **Create**. Copy the **URL** (Overview) and an **Admin key** (Keys).

### Create (CLI)

```bash
az search service create --name mysearch12345 \
  --resource-group rg-db-demo --sku free --location centralindia
```

### Create index, insert, and get (REST)

```bash
# Create index
curl -X PUT "https://mysearch12345.search.windows.net/indexes/students?api-version=2024-07-01" \
  -H "Content-Type: application/json" -H "api-key: <admin-key>" \
  -d '{
    "name": "students",
    "fields": [
      {"name":"id","type":"Edm.String","key":true},
      {"name":"name","type":"Edm.String","searchable":true},
      {"name":"course","type":"Edm.String","filterable":true,"searchable":true}
    ]
  }'

# Insert documents
curl -X POST "https://mysearch12345.search.windows.net/indexes/students/docs/index?api-version=2024-07-01" \
  -H "Content-Type: application/json" -H "api-key: <admin-key>" \
  -d '{"value":[
    {"@search.action":"upload","id":"S001","name":"Ravi","course":"DevOps"},
    {"@search.action":"upload","id":"S002","name":"Sita","course":"Azure"}
  ]}'

# Get one document
curl "https://mysearch12345.search.windows.net/indexes/students/docs/S001?api-version=2024-07-01" \
  -H "api-key: <admin-key>"

# Search
curl "https://mysearch12345.search.windows.net/indexes/students/docs?api-version=2024-07-01&search=Ravi" \
  -H "api-key: <admin-key>"
```

## 8. Azure Data Explorer (Time Series and Log Analytics)

### Create (Portal)
1. Easiest for practice: open the free cluster page at `dataexplorer.azure.com` and sign in to create a **free cluster**.
2. Paid option: search **Azure Data Explorer Clusters**, click **Create**, choose a dev/test SKU, and create a database in the cluster.

### Create table, insert, and get (KQL)
In the **Query** window:

```kusto
.create table Students (id: string, name: string, course: string)
```

```kusto
.ingest inline into table Students <|
S001,Ravi,DevOps
S002,Sita,Azure
```

```kusto
Students

Students
| where course == "DevOps"

Students
| summarize total = count() by course
```

> `.ingest inline` is meant for small tests. Production loads use ingestion from Blob storage, Event Hubs, or IoT Hub.

## Quick Comparison

| Database | Create structure | Insert | Get |
|---|---|---|---|
| Cosmos DB for NoSQL | database + container | New Item (JSON) | `SELECT * FROM c` |
| Cosmos DB for MongoDB | database (collection on first insert) | `insertOne` | `find` |
| Cosmos DB for Cassandra | keyspace + `CREATE TABLE` | `INSERT INTO` | `SELECT` |
| Cosmos DB for Gremlin | database + graph | `g.addV(...)` | `g.V()...` |
| Table Storage | `az storage table create` | `az storage entity insert` | `entity show / query` |
| Azure Managed Redis | cluster | `SET`, `HSET` | `GET`, `HGETALL` |
| Azure AI Search | index | `docs/index` upload | `docs?search=` |
| Data Explorer | `.create table` | `.ingest inline` | KQL query |

## Cleanup (avoid charges)

Deleting the resource group removes everything created in this guide:

```bash
az group delete --name rg-db-demo --yes --no-wait
```

In the portal: **Resource groups**, select `rg-db-demo`, **Delete resource group**, type the name to confirm.
